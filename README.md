## 📸 Key Mechanics

- **Stage 12: Omega Core (3,379 Bricks)**: Exact replica of the viral screenshot with 3,379 bricks and an **indestructible** horizontal steel bar requiring curved flank shots to breach.
- **Ribbon Motion Trail (优美的曲线)**: Smooth multi-point catmull-rom curve with glowing neon decay.
- **Procedural Web Audio API**: Square/triangle sound synthesis, pentatonic combo escalation, and deep sub-bass drop on initial barrier breach.
- **Spatial Partitioning Collision Grid**: Ultra-optimized collision detection running locked at 60/120 FPS with 4x sub-stepping physics.
- **Auto-Progression & Stage Select**: Clear a stage to seamlessly advance to the next, or use the top dropdown to jump directly to any stage!

## 🎮 Controls

- **Desktop**:
  - `Mouse` or `←` / `→` arrow keys: Move paddle
  - `Space` or `Left Click`: Launch ball / advance stage
  - Top buttons: Toggle sound, restart, or switch stages
- **Mobile / Touch**:
  - `Drag`: Smooth 1:1 paddle tracking
  - `Tap`: Launch ball / advance stage
